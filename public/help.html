Teacher help

Export, import, find.

Everything needed to use ChatFind privately on a phone or computer.

Android

Export from WhatsApp

  1. Open the required private chat or group.
  2. Tap ⋮ → More → Export chat.
  3. Choose Include media when PDFs, photos or documents are needed.
  4. Save or share the resulting ZIP file.
iPhone

Export from WhatsApp

  1. Open the required private chat or group.
  2. Tap the chat or group name at the top.
  3. Choose Export Chat → Attach Media.
  4. Choose Save to Files and keep the ZIP file.
ChatFind

Import and search

  1. Return to ChatFind and press Choose export.
  2. Select the WhatsApp ZIP or TXT file.
  3. Search by person, group, date, keyword or file type.
  4. Tap a filename to open it or choose View context.
Storage and safety

Backup, move or clear your library

Move to another device

Download an encrypted backup. Transfer the `.chatfind-backup` file to the new device and restore it using the exact same password.

Clear chat history

In ChatFind, open Encrypted backup & restore, then press Clear all local data and confirm. This removes chats, files and stars from that browser only.

Missing PDF or image

Download the file inside WhatsApp first. Export the chat again with media and re-import it; duplicates are skipped automatically.

Privacy

Imported data remains in the current browser. Sharing the ChatFind link does not share anyone's chat history.
