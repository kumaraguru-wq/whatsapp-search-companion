# ChatFind — Teacher Quick Guide

Live site: https://kumaraguru-wq.github.io/whatsapp-search-companion/

ChatFind searches an exported WhatsApp chat privately on your phone or computer.
No account is needed, and imported information is not uploaded to a server.

## 1. Export a WhatsApp chat

### Android

1. Open the required private chat or group in WhatsApp.
2. Tap **⋮ → More → Export chat**.
3. Choose **Include media** if you need PDFs, photos or documents.
4. Save or share the resulting ZIP file to a location you can find.

### iPhone

1. Open the required private chat or group in WhatsApp.
2. Tap the chat or group name at the top.
3. Choose **Export Chat → Attach Media**.
4. Choose **Save to Files** and save the ZIP file.

## 2. Import and search

1. Open the ChatFind live site.
2. Press **Choose export** and select the WhatsApp ZIP or TXT file.
3. Wait for the chat to appear in **Your chat library**.
4. Search using a name, keyword, date, group or file type.
5. Tap a filename to open it, or press **View context** to see its original message.
6. Press the star beside an important result to add it to **Quick access**.

Re-importing a newer export of the same chat adds new information and skips
duplicates automatically.

## 3. Install ChatFind

- **Android/desktop:** use the **Install app** suggestion when it appears.
- **iPhone:** open the site in Safari, tap **Share**, then **Add to Home Screen**.

## 4. Protect or move your library

1. Under **Encrypted backup & restore**, enter a password of at least eight characters.
2. Confirm it and press **Download encrypted backup**.
3. Keep the downloaded `.chatfind-backup` file and password separately.
4. On another device, select that file, enter the same password, and press
   **Restore encrypted backup**.

The password alone is not enough; restoring requires both the backup file and
the exact password. ChatFind cannot recover a forgotten password.

## Troubleshooting

- **A file will not open:** it was probably not included in the WhatsApp export.
  Download it inside WhatsApp, export again with media, and re-import.
- **An older screen appears:** refresh the page once or close and reopen the installed app.
- **Chats disappeared after clearing browser data:** restore the latest encrypted backup.
- **Privacy:** imported chats remain in that browser's local storage and are not
  visible to other users through the GitHub Pages link.
